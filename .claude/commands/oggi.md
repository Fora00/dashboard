description: Pick today's focus (1-3 Things to-dos tagged 🎯) and show it on the dashboard (Life → Oggi, also on the phone)
---

Daily focus lives in Things (tag `🎯`, which already exists) and is mirrored to the dashboard's **Oggi** section through an import link (like `/settimana`). Personal titles never go in this repo: the lines only travel in the link, which is opened on the Mac and then synced to the owner-only table.

0. **Snapshot:** the chores section is switched off for now: **do not run `chores-sync.py`**; the link carries no chores unless `--chores` is passed on purpose. Habits are no longer a snapshot: they live in the dashboard's Habits page and Life reads them live, so the Streaks app is retired (2026-11-18): **do not run `streaks-sync.py`**.
0b. **Meal diary:** run the `/meal-reconcile` flow for the last 2 days (yesterday and today; `/meal-reconcile 2`) so the diary's estimates are fresh. It has its own confirmation (diff, then he OKs before anything is written), so do it here as a short step: if there is nothing to reconcile, say so in one line and move on; if he skips it, move on. Never let it block the focus steps.
1. **Read** (AppleScript; use `whose` filters on lists/tags, never loop over every to-do, it times out): to-dos in Today, to-dos tagged `🎯` (his picks or leftovers: see step 2), to-dos tagged `🐌 in ritardo` (open ones: the dashboard's "🐌 In ritardo" subsection), the week's ⭐ to-dos, and today's events in `_sync/calendar/upcoming.md` (run `_sync/pull.sh` if stale).
2. **Clean up: picks vs leftovers.** For each `🎯` read its `modification date` (AppleScript) and yesterday's `life_day_focus` rows. Modified today and not in yesterday's focus = **his pick for today**: keep it, no question. Only the others are leftovers: ask done / still today / drop. A leftover he does not keep for today and is not done **loses `🎯` and gets `🐌 in ritardo`** (his rule, 2026-11-21: no need to ask; say it in one line) and goes in the link as `"~Title"`. Done ones: remove `🎯`.
3. **Propose only the free slots** (3 minus his picks) for today, preferring the week's ⭐ items, then what has a deadline or a person waiting (`ping` tag), sized to the free hours in the calendar. One line each with why. Ask before tagging.
4. **Apply** after his OK: make sure each is scheduled for today and add the tag `🎯` (keep its other tags). A title he names: **search Things first** (open to-dos whose name contains its key words); if it looks like an existing to-do, use that one or ask which, never create a near-duplicate. Only a genuinely new idea is created with `_sync/things-add.sh "Titolo" today "" 🎯 "" <list>` first.
5. **Dashboard:** `cd ~/Dev/personal/dashboard && npm run --silent life:oggi-link -- <YYYY-MM-DD today> "Titolo 1" "Titolo 2"` prints the link (or one error per line: fix and rerun); chores are left out unless `--chores` is passed. Titles = the Things titles, without emoji prefixes. **Save now appends** (it never replaces the day's lines; titles already there are skipped); a title starting with `!` goes into the 🚨 Urgenze subsection (outside the 3-line focus, up to 6); a title starting with `~` goes into the 🐌 In ritardo subsection (up to 6): pass every open `🐌 in ritardo` to-do as `"~Title"`, they do not count toward the 3 focus lines. A to-do enters the 🐌 list automatically when it was a `🎯` leftover not kept for today (step 2), or when Francesco tags it (for others far behind their date, propose the tag); it leaves when done or untagged. Done lines are only set by ticking in the app. `open "<link>"` on the Mac (a browser signed in to the dashboard, not one that syncs history/tabs); the page shows a preview (focus) and he taps **Salva**, which replaces today's lines, and syncs to the phone. Never open the link on iOS. If he skips it, just say so.
6. End with the list, in one line.

Rules: max 3; a `🎯` must be a real Things to-do; never remove the weekly ⭐ / ⭐️ from here; the link is never saved without his tap.
